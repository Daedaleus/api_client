# Keyboard shortcuts

On macOS use **Cmd** instead of **Ctrl**.

| Keys | Action |
|---|---|
| **Ctrl+Enter** | Send the active request – also from the script and body editors |
| **Ctrl+S** | Save the active request |
| **Ctrl+N** | New request (an unsaved tab) |
| **Ctrl+E** | Go to the environment picker |
| **Ctrl+F** | Search in the response body |
| **Ctrl+Space** | Suggestions in the script editor |
| **Esc** | Close a dialog or menu |

Menus, dialogs and the tree work with the keyboard too: **Tab** moves
between controls, the arrow keys move in menus, **Enter** activates.
